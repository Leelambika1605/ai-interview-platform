# AI Mock Interview Platform

An AI-powered web application designed to help students and job seekers practice technical interviews and improve their interview confidence.

## Features

- User registration and login
- Job role selection
- Technical interview practice
- Interview answer evaluation
- Scores and feedback
- OTP-based password reset

## Technologies Used

- **Frontend:** React, Vite, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL
- **Version Control:** Git and GitHub

## Getting Started

### Prerequisites

- Node.js and npm
- PostgreSQL
- Git

### Clone the Repository

```bash
git clone https://github.com/Leelambika1605/ai-interview-platform.git
cd ai-interview-platform
```

### Run the Backend

```bash
cd backend
npm install
node src/server.js
```

### Run the Frontend

Open a second terminal:

```bash
cd frontend
npm install
npm run dev
```

Configure the required environment variables before starting the backend. Keep passwords, email credentials, and API keys private.
